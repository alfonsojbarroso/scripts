# Scripts

A collection of simple shell scripts for running development services with Docker.

## Services

| Script | Service | Port |
| --- | --- | --- |
| `kafka.sh` | Apache Kafka | `9192` |
| `sonar.sh` | SonarQube Community | `9000` |

## Usage

Make a script executable and run it:

```sh
chmod +x kafka.sh
./kafka.sh
```

The scripts require Docker to be installed and running.
